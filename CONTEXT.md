## Prisma Schema Work
Implemented in `prisma/schema.prisma`:

1. Prisma setup
- `generator client` with `prisma-client-js`
- PostgreSQL datasource using `env("DATABASE_URL")`

2. Enums
- HoldingStatus: OWNED, WATCHLIST
- Recommendation: BUY, HOLD, SELL, WATCH
- Sentiment: BULLISH, NEUTRAL, BEARISH, MIXED
- TrendDirection: STRONG_UPTREND, UPTREND, SIDEWAYS, DOWNTREND, STRONG_DOWNTREND
- RiskLevel: LOW, MEDIUM, HIGH, CRITICAL
- AlertSeverity: INFO, WATCH, IMPORTANT, CRITICAL
- PredictionHorizon: ONE_DAY, ONE_WEEK, ONE_MONTH
- PredictionDirection: UP, DOWN, FLAT

3. Models
- User
- UserPreference
- Portfolio
- Holding
- Stock
- PriceSnapshot
- TechnicalSnapshot
- FundamentalSnapshot
- NewsArticle
- EarningsEvent
- MacroEvent
- AIReport
- PortfolioSummary
- Prediction
- PredictionOutcome
- Alert
- DataIngestionLog

4. Relationships
- User -> many Portfolios
- User -> one UserPreference
- Portfolio -> many Holdings
- Portfolio -> many PortfolioSummaries
- Holding -> belongs to Portfolio and Stock
- Stock -> many related stock entities (holdings/snapshots/news/earnings/reports/predictions/alerts)
- AIReport -> required Stock, optional Holding
- Prediction -> required Stock, optional Holding and AIReport
- PredictionOutcome -> exactly one Prediction
- Alert -> required User, optional Stock
- DataIngestionLog -> standalone

5. Delete behavior
- User deletion cascades to preferences, portfolios, alerts
- Portfolio deletion cascades to holdings and summaries
- Stock deletion cascades to dependent stock records
- Optional relations use `onDelete: SetNull` where appropriate

6. Indexes
- Added practical indexes for userId/stockId where relevant
- Added `ticker` and `sector` indexes on Stock (`ticker` also remains unique)
- Added `capturedAt` indexes on snapshot tables
- Added `publishedAt` indexes on NewsArticle and MacroEvent
- Added `recommendation` and `sentiment` indexes on AIReport
- Added `horizon` and `predictionDate` indexes on Prediction
- Added `severity`, `isRead`, and `createdAt` indexes on Alert
- Added `jobName`, `ticker`, `status`, and `startedAt` indexes on DataIngestionLog

## Seed Script Work
Implemented in `prisma/seed.ts`:
- Uses `PrismaClient`
- Idempotent upsert flow
- Upserts demo user: `demo@example.com`
- Upserts user preferences for the demo user
- Creates/updates demo portfolio (`Demo Portfolio`)
- Upserts stocks: AAPL, MSFT, NVDA
- Upserts holdings in demo portfolio as `OWNED`
- Includes shares, average cost, and thesis for each holding
- Includes error handling with process exit code and `prisma.$disconnect()` in finally
